# Mesh asset library

Cooked by `cooker/cook.py` into `assets/library/<id>/` (meters, Z-up, footprint centered at the
origin, lowest point at z=0). Every asset is CC0 1.0 (public domain); credit is given as a courtesy.

Each folder holds `meta.json`, `visual.glb` (Z-up, the page rotates it), `visual_<k>.obj` (MuJoCo
visual geoms), `hull_<k>.obj` (CoACD convex pieces, MuJoCo collision) and `thumb.png`.
